铁律 4（全球 M&A / 战略合作 / 大厂动向必扫）：每天必须显式扫描以下查询，结果有则必纳入热点新闻头部：

铁律 5（来源平衡）：每条新闻必须使用其主要报道源，不要全部回退到一两家中文聚合媒体；优先选有原始链接 + 一手报道的来源。

  - 6.2 同事件不同 URL：即使 URL 不同，但事件主体（同公司+同动作+同金额/同对象）已在过去 7 天发过的，原则上跳过；除非有明确进展（带【进展】标识）
  - 6.3 板块内自重复禁止：同一篇文章/同一事件不允许在同一日的两个板块各发一次（如 Stanford HAI 数据不要同时进「企业级」和「深度报告」）

      d) 用过滤后的清单（kept items）作为最终入选条目；如果某板块条目数 < 4，必须补足
   8. ⚠️ 验本地 JSON schema（2026-05-15 新增铁律，对应「日报推送后必须自检质量」）：
      在 cron-sync-event.sh 跑完后，**必须**对 `src/data/daily/$(date +%Y-%m-%d).json` 运行以下自检脚本：
      ```bash
      python3 << 'PYEOF'
      import json,sys

        d=json.load(open(f'/root/.openclaw/workspace/projects/ai-daily/src/data/daily/{__import__("datetime").date.today().isoformat()}.json'))

      ```

      - 4 板块（news/enterprise/coding/report）全到位，每板块 ≥ 3 条
      - closing 是「本期速览」用户可见内容——**绝对不能含「铁律 4 扫描结果」「审计日志」等内部元数据**

   - 任一项不通过 → 必须重新搜索 / 重写 / 替换条目，不允许跳过自查
